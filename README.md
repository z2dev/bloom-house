# ✨ About The Project

Bloom House is a modern web-based e-commerce platform created to provide customers with a smooth and enjoyable online plant shopping experience.

The website allows users to:

- Browse plant categories
- Search and filter products
- Add plants to favourites
- Place orders
- Download invoices
- Review purchased plants
- Manage their accounts

The system also includes a complete admin panel for managing products, orders, FAQs, customer messages, and website content.

🌱 The project was inspired by a real local plant nursery business to create a realistic digital business experience.

# 🚀 How To Run The Project

## 1️. Install XAMPP

Download XAMPP from:

[XAMPP Official Website](https://www.apachefriends.org/index.html?utm_source=chatgpt.com)

---

## 2️. Move The Project

Place the project folder inside:

```text id="n8khk9"
xampp/htdocs/
```

---

## 3️. Start Services

Open XAMPP and start:

* Apache
* MySQL

---

## 4️. Import Database

Open:

```text id="v4q2zv"
http://localhost/phpmyadmin
```

Create a database named:

```text id="v7l7l0"
bloom_house
```

Then import:

```text id="0uwg04"
bloom_house.sql
```

---

## 5️. Run The Project

Open the browser and visit:

```text id="txa4ij"
http://localhost/bloom-house
```
